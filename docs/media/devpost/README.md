# Devpost gallery images

Generated by `scripts/devpost-shots.mjs` (Playwright, Pixel 7 emulation, local production build). Each image is 2400x1600 (3:2) PNG.
Phone screenshots are real captures of the app; the touch dot is the app's own finger indicator. Nothing is painted over the app.
The dev-only debug text under the canvas ("First hold: dx=...") is hidden at capture time by setting the element's visibility from the capture script (no app code changed).
Upload order: 01, then 03 right after the thumbnail, then 02, 04, 05, 06, 07, 08, 09, 10.

## Re-run
1. `cd frontend && VITE_API_URL=https://ghost-touch-api.onrender.com npm run build && npx vite preview --port 4180 --strictPort`
2. Raw Mode (06): start a local backend with every AI provider key blank so uploads take the real OpenCV path: `cd backend && OPENAI_API_KEY= GEMINI_API_KEY= NEBIUS_API_KEY= VISION_PROVIDERS= ALLOWED_ORIGINS=http://localhost:4180 .venv/Scripts/python.exe -m uvicorn app.main:app --port 8001`
3. Teacher editor (10): build a second copy with the flags on, outside the repo, and preview it: `cd frontend && VITE_FEATURE_GUIDE=1 VITE_FEATURE_SHARE=1 VITE_API_URL=https://ghost-touch-api.onrender.com npx vite build --outDir <tmp>/gt-dist-flags --emptyOutDir && npx vite preview --outDir <tmp>/gt-dist-flags --port 4181 --strictPort`
4. `node scripts/devpost-shots.mjs` (or `--only=03,05`). Warm the Render backend first (open its /api/v1/health), or 05 shows a timeout and is dropped.

## Captions to paste

- `01-start.png`: Start screen: a single full-screen button. Feel diagrams you can't see, on an ordinary Android phone.
- `02-capture.png`: Capture screen: take a photo, choose an image or a PDF page, or open one of three built-in samples that work without a network.
- `03-explore-triangle.png`: Explore a right triangle by touch. The white dot is the app's own finger indicator. On Android the phone vibrates along lines and gives a double pulse at corners while speaking the corner label.
- `04-explore-graph.png`: A function graph (y = sin x). The pitch of a continuous tone follows the height of the curve under the finger.
- `05-ask.png`: Ask a question about the diagram ("Where is the right angle?"). Typed here; voice input is also supported. The answer comes from the diagram's own geometry and facts.
- `06-raw-mode.png`: Raw Mode: when the AI cannot understand a photo, classical OpenCV edge detection still turns the outlines into lines the student can explore.
- `07-languages.png`: The Explore screen in Hindi. The interface and speech are available in English, Hindi and Gujarati (Hindi and Gujarati are machine-translated and awaiting native-speaker review).
- `08-settings.png`: Settings: language, speech speed, and guidance for turning on touch feedback on Samsung, Pixel, OnePlus and Xiaomi phones.
- `09-saved.png`: Saved diagrams are stored on the phone and can be reopened offline.
- `10-teacher-editor.png`: In testing: the teacher editor, where a sighted teacher can add and correct points and edges (off by default; switched on in Settings).

## How the shots were made
- Samples are the built-in offline diagrams. Only two things use the live backend: the Ask answer (05) and one real AI-read upload (09, so the saved card has a real title). A full run makes 2 live calls; the script caps live calls at 3 per run.
- Raw Mode (06) comes from the real backend running locally with all AI provider keys blank, so the upload takes the genuine OpenCV Raw Mode path. The image uploaded is a synthetic photo from research/samples.
- The question in 05 is typed; headless Chrome has no microphone. The answer text is the live backend's.
- Font: Atkinson Hyperlegible (the app's own self-hosted font; Inter is not installed on this machine). Hindi and Gujarati glyphs come from system fonts.

## Skipped or notes
- 05: the app clears the input after Send, so the question text is not visible in the shot; only the answer is. The answer is real (live backend: "The right angle is at point C. Angle C measures 90 degrees."). A first attempt hit a Render cold start ("Request timed out") and was discarded; the script now drops any shot whose status shows a failure.
- 06: the sample photo contains printed labels, so Raw Mode traces the text as well as the triangle. This is real Raw Mode output, not cleaned up.
- 11 (Guide my finger): not captured. With the flag and the Settings toggle on, Guide has no visible control on the Explore screen (it is voice-driven), so there was nothing real to photograph.
- 01 shows the app's own text under the button, "TalkBack & touch ready". That is app copy, not a claim added here; remove or retake the shot if you do not want it in the gallery.
- The app was not changed. No env files were read.
