# T06b + T07 review
Reviewer: Claude Code subagent | Verdict: FIX FIRST

Scope: committed versions only (HEAD). T09/Ask edits in the working tree were ignored. Nothing was run on a phone; every on-device claim below is unverified.

Summary: the build is green and the structure follows the briefs. The ownership, architecture and tuned-value checks pass. FIX FIRST because of four real defects that a blind user would hit on the phone:
1. A stale history entry makes the first Android Back after leaving Explore do nothing.
2. The centre tick is silently skipped on some new holds.
3. The bar tone sticks after leaving a bar.
4. PDFs are rendered at 72 dpi.
