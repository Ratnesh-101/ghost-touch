## Checked and found fine
- Unvalidated model output never reaches the response in the AI paths: both `scene` values come from `validator(...).scene`. Fallback to the next provider happens only on `VisionError`; invalid content takes the single retry then Raw Mode (main.py:134-170). Retry runs on the answering provider and is skipped when under 3 s remain.
- No caching exists, so failures or Raw Mode results cannot be cached.
- Secrets: keys come from env only; `_redact_secrets` is applied to SDK, httpx and HTTP-body errors; no key is logged. `git grep "nvapi-"` / `"AIza"` hits only docs text, no keys. `.env` is gitignored, `.env.example` is allowed.
- Deadline: `asyncio.timeout(15)` cancels `wait_for` (Gemini) and the httpx call (NVIDIA); per-provider cap 8 s via `ProviderChain.call_timeout`. `httpx` timeout is per phase rather than total, but the outer deadline covers it.
- NVIDIA: 180 KB fit loop terminates; fences are stripped; 429, 5xx, timeouts and empty choices map to `VisionError`; key redaction is tested.
- Prompt text matches CLAUDE.md plus the vocabulary block; retry adds the vocabulary sentence.
- Dependencies: only `httpx` was moved to runtime.
