# User Test Results Template & STEMergent Summary

> **Confidentiality Notice:**  
> Never enter real student names, phone numbers, email addresses, or physical addresses into this document. Use anonymous participant IDs (`P1`, `P2`, `P3`, `P4`).  
> All fields below use standardized placeholders ready for in-session note taking.  
>
> **Facilitator Notice on Languages:**  
> Ghost Touch supports English, Hindi, and Gujarati. **Hindi and Gujarati are machine-translated and have not yet been validated by native speakers.** Documenting participant and educator feedback on vocabulary, phrasing, and pronunciation clarity is an explicit objective.  
>
> **Device Notice:**  
> The application has not yet undergone physical on-device motor validation; real-device feedback collected here provides baseline calibration data.
