## How to run parallel agy lanes (what worked)
1. `git worktree add ../gt-lane-<x> -b agy/<x>` from `main`; link deps: `cmd //c "mklink /J <lane>\frontend\node_modules <main>\frontend\node_modules"` and the same for `backend\.venv`. **Never `npm ci` in the main folder while lanes run** (they share its node_modules). For dependency work use a separate clone in the scratchpad (own node_modules).
2. Write `docs/briefs/agy-<x>.md` (goal, allowed files, forbidden files, Definition of Done, "end with a Commit groups section"). Avoid literal exploit strings in briefs: Gemini's filter blocked one run.
3. Launch: `PATH` must include agy (`%LOCALAPPDATA%\agy\bin`) AND node, then `(cd lane && bash scripts/agy-run.sh /tmp/<prompt>.txt agy-<x> &)`. Max 4 at once. Without node on PATH agents cannot run tsc/tests.
4. Monitor `logs/agy/agy-<x>.out.txt` becoming non-empty. Agents sometimes finish without a report or stop early: always re-run the gates yourself.
5. Review the diff against scope; run tsc, tests, build, pytest, ruff; fix small things yourself and note them in `docs/reviews/agy-<x>.md`; commit per group; `git merge --no-ff` into main; re-run gates; push.
