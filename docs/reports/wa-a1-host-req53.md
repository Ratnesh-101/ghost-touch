# WA-A1: Requirement 53 and GH-01..GH-12 against the code (en / hi / gu)

Auditor: Kiro (read-only). Read first: `CLAUDE.md`, `.kiro/steering/*.md`, Requirement 53 (`requirements.md:839`), `docs/reports/ghost-host-audit.md`. No source file was changed, no build run, nothing committed. No secret was opened.

Method: read `core/hostPolicy.ts`, `flow/start.ts`, `flow/ask.ts`, `flow/navigation.ts`, `drivers/speech.ts`, `screens/Start.tsx`, the Explore ask/focus code, the three tables in `i18n/index.ts` (en 55-662, hi 666-1275, gu 1279-1889), `explore.css`, `CrashScreen.tsx`, `App.tsx` call sites, and the Ghost Host tests. I did not run the tests. Hindi and Gujarati were read in the source file; I judge them only for structure (action, location, no joke), not for translation quality.

## 1. Summary

Done well: the pure policy core, the Start greeting and tap sequence, the Capture line, the focus move to the typing box, the language-offer flag, the voice-notice language name, the Back wording, the `min-height` fix, and joke-free hi/gu text. The main gap is that **eight of the eleven `host.*.next` lines exist in the tables but no screen speaks them**, and **`hostPolicy` is not used by any app code**, so the failure counter and joke rules (53.6) are not enforced at runtime.

Counts: criteria 53.1 to 53.14 = 5 met (53.2, 53.7, 53.12, 53.13, 53.14), 7 partly met (53.1, 53.4, 53.5, 53.8, 53.9 as met with a note, 53.10, 53.11), 2 unmet (53.3, 53.6). GH-01..GH-12 = 8 met (01, 03, 04, 05, 07, 10, 11, 12), 3 partly met (02, 06, 09), 1 unmet (08). Section 3 and 4 give the file:line for each. W-numbers in section 2 are the defects.
