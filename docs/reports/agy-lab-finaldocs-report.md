## 4. Claims That Could Not Be Verified (Honest Limitations)

1. **Physical Device Touch & Haptic Response:** The application's tactile vibrations, double-tap-and-hold relative cursor exploration, and Web Speech voice recognition have been verified through desktop emulation (headless Brave at 390×844 and 1440×900), Node/Vitest component tests, and mathematical property tests. However, live tactile sensation and TalkBack interaction on a physical Android handset (OnePlus Nord CE6) cannot be verified in a headless environment.
2. **Native-Speaker Linguistic Quality:** UI strings and spoken announcements in Hindi (`hi`) and Gujarati (`gu`) are machine-translated and have not yet undergone proofreading by native-speaking educators.
3. **Formal Stakeholder Brand Approval:** Hand-crafted SVG brand assets (`logo-full.svg`, `logo-mark.svg`, `favicon.svg`, `Mascot.tsx`) are integrated into the application, but await final formal sign-off from the repository owner.
4. **Live Multimodal Vision Inference:** Deployed production instances on Render fall back to OpenCV Canny edge detection (Raw Mode) in the absence of funded production Gemini API keys and due to free-tier cold-start latency budgets.
