# Lane g4-semantic-voice (agy), frontend
Read AGENTS.md, `docs/briefs/guide-share-contract.md` (Global rules + Guide contract) and `docs/briefs/semantic-targets-spec.md` (the shared definitions: follow it exactly).
Context: voice "find <label>" / "take me to <label>" only resolves labelled elements, so "find the peak" does not work (known limit).
Goal: semantic voice targets for Guide, pure and tested.
Allowed files: new `frontend/src/guide/semantic.ts` (+ export from `guide/index.ts`), `frontend/src/flow/commands.ts` (parse the phrases and resolve through `semantic.ts`; keep every existing command and test working), `frontend/src/i18n/index.ts` (new keys en/hi/gu, e.g. `guide.semantic.none.*`), new tests `frontend/tests/guide.semantic.*.test.ts(x)` (new files only), `docs/PHONE_TEST.md` (remove the statement that "find the peak" does not work; add the working phrases to the guide step), `docs/user-test/translation-review.md` + `.csv`, report `docs/reports/agy-g4-semantic-voice-report.md`, `docs/BUILD_LOG.md`.
Forbidden: `frontend/src/core/**`, `.kiro/**`, `.env*`, backend, existing `*.prop.test.ts`.
Implement `resolveSemantic(scene, name): ResolvedTarget | null` (names: 'peak'|'trough'|'origin'|'tallestBar'|'shortestBar'|'rightAngle'|'longestSide'). Parse the phrases into those names only when the guide is active (flag off => existing fall-through behaviour, like the other guide commands). The guide then starts toward the target like "take me to B". When no target exists, speak the plain "no X in this diagram" line (ONE speak call; the speech driver cancels the previous utterance).
Acceptance tests: each name on the three bundled samples in `frontend/public/samples/` (triangle: right angle at B, longest side is the hypotenuse AC; sine: peak near a quarter of the period, trough near three quarters, origin only if axes are set; bars: tallest/shortest match values), tie rules, nothing-matches case, flag off falls through, phrases en/hi/gu parse, fast-check property: peak.y <= every polyline vertex y; trough.y >= every vertex y; a rightAngle target (if any) has an angle within tolerance. Run the frontend tests, tsc and build; report real numbers.
