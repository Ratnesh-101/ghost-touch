# Audit a7-bughunt-core
Read `docs/briefs/audit-common.md` first (rules and report format; scope here is the WHOLE app, existing features included). Report: `docs/reports/audit-a7-bughunt-core.md`.
Files: `frontend/src/**` (App.tsx, screens, flow, drivers, api, components, i18n), `backend/app/**`.
Goal: find real functional bugs in the core user journeys by tracing code paths with concrete inputs: Start -> Capture (camera, file, PDF, samples, downscale) -> loading -> Explore (pointer events, hit testing, haptics effects, speech, tone, axes crossings, two-finger gestures, Ask, voice commands, rate/language changes) -> Correct -> Saved diagrams (IndexedDB quota, eviction, corrupt records) -> Back navigation; and the backend /scene, /ask, /validate pipelines (fallback chain, retries, Raw Mode, scene cache, concurrency cap, timeouts, cancellation).
Hunt for: state machines that can get stuck (loading never ends, busy flag not reset on error/abort, double taps), race conditions between async results and screen changes (late scene response after the user pressed Back, late speech or listen callbacks), unhandled promise rejections, missing cleanup of listeners/timers/streams (camera stream left on, audio context never closed, object URLs not revoked), error paths that stay silent for a blind user (every failure must be spoken), off-by-one or unit errors in geometry/hit testing (letterboxing, devicePixelRatio, rotation/resize mid-gesture), `null`/`undefined`/NaN handling on scenes from the backend, i18n fallbacks and string interpolation bugs (`{name}` left in output, plural forms), numbers formatting in hi/gu, accessibility regressions (focus loss after screen change, missing live-region announcements, targets under 48 px), memory growth in long sessions (history stacks, caches without bound), test gaps for the above (list the 10 most valuable missing tests).
Skip anything already described in `docs/reports/audit-a1..a5-*.md` and `audit-bugs.md` unless you can show it is still present in the current code.
