# Lane lab-brand: the Ghost Touch logo, favicons, PWA icons, social preview, mascot

Read `docs/briefs/lab-spec.md` first. Create an ORIGINAL logo (not a known character, brand or mascot) and the assets around it.

## Logo concept
- Mark: a friendly "creature" phone. A rounded phone outline with a stitched seam (suture marks) across it, one neck bolt on the side, and three short vibration arcs coming off the edge (the "touch"). A small glowing triangle on the screen (the diagram it feels). Life green `#39ff88` strokes, copper bolt, bone-coloured stitches, transparent background.
- Wordmark: "Ghost Touch" in Atkinson Hyperlegible Bold with a thin stitch line under "Touch". In SVG files, convert the text to outlines is not possible without tools, so use `<text>` with `font-family="Atkinson Hyperlegible, system-ui, sans-serif"` and `font-weight="700"` in the full logo, and note in the report that rasterised PNGs embed the font via the build script (see step 5). In the app component the real text stays HTML text.
- It must read at 16 px (favicon): at small sizes drop the stitches and arcs and keep only phone + triangle + bolt.

## Allowed files
- `frontend/public/brand/**` (new): `logo-mark.svg`, `logo-full.svg` (mark + wordmark, horizontal), `logo-mono.svg` (single colour, for light backgrounds), `logo-maskable.svg` (solid `#0b0e0c` background, mark inside the 80 % safe zone), `og-image.svg` (1200x630 source: logo-full + "Feel diagrams you can't see" + the three-organs line: Nerves = vibration, Eyes = vision AI, Voice = theremin and speech, Lab style). Hand-written clean SVG, each under 6 KB (og-image.svg may be up to 10 KB), each with `<title>`.
- `frontend/public/favicon.svg` (the simplified 16 px design)
- `frontend/src/components/Logo.tsx` (new), `frontend/src/components/Mascot.tsx` (redraw), their tests (`frontend/tests/logo.test.tsx` or `.ts`; keep `tests/mascot.test.ts` passing and extend it)
- `frontend/index.html` (icons, theme-color, og: and twitter: tags), `frontend/vite.config.ts`: change ONLY the `manifest` block (icons, `theme_color: '#0b0e0c'`, `background_color: '#0b0e0c'`; keep name, display, start_url). Another lane edits the `globPatterns` line of this file; do not touch it.
- `scripts/build-brand.mjs` (new), `README.md` (insert `frontend/public/brand/logo-full.svg` at the very top, centred, with alt text "Ghost Touch"), `docs/design/LOGO.md` (new), `docs/reports/agy-lab-brand-report.md`

## Forbidden
Screens, i18n, tokens.css/global.css, backend, core, prop tests, `.env*`, package.json (no new dependency).

## Do
1. SVG assets as listed. Colours may be literal hex inside the SVG files (assets are not components) but should match the lab palette: green `#39ff88`, copper `#c9803a` (adjust for contrast), bone `#e8dfc8`, charcoal `#0b0e0c`.
2. `Logo.tsx`: props `variant: 'full' | 'mark'`, `decorative?: boolean`, `className?`, `height?: number`. Inline SVG (no network, styles by `currentColor` and CSS variables where it helps). If `decorative`, `aria-hidden="true"` and `focusable="false"`; otherwise `role="img"` with `aria-label="Ghost Touch"` (pass the label through `t('app.name')`). The visible page heading must stay real text: the Logo is never the only content of an `<h1>`.
3. `Mascot.tsx` redraw: a friendly stitched phone creature with a bolt and a glowing screen-face, original design. Keep it decorative (`aria-hidden`), keep the existing props (`className`, `size`), stay under the size limit enforced by `tests/mascot.test.ts`, and keep that test passing.
4. `index.html`: `<link rel="icon" href="/favicon.svg" type="image/svg+xml">`, `<link rel="icon" href="/favicon.ico" sizes="48x48">`, `<link rel="apple-touch-icon" href="/apple-touch-icon.png">`, `theme-color` `#0b0e0c`, `og:title`, `og:description`, `og:type`, `og:image`, `twitter:card` = `summary_large_image`, `twitter:title`, `twitter:description`, `twitter:image`. Use the RELATIVE path `/brand/og-image.png` for the image (the deployed domain is not known yet) and say in your report that crawlers need an absolute URL, so the owner must set the real domain once deployed.
5. `scripts/build-brand.mjs`: a reproducible Node script (no new dependencies) that renders the SVGs to PNG with headless Chromium through `playwright-core` (imported lazily; if the import fails print a clear message). Browser path from env `BRAND_BROWSER` or a default (Edge or Chrome on Windows, `chromium` elsewhere). Embed the Atkinson font from `frontend/src/assets/fonts/*.woff2` via a base64 `@font-face` inside the page it screenshots. Outputs: `frontend/public/apple-touch-icon.png` (180), `frontend/public/icons/icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `frontend/public/brand/og-image.png` (1200x630), `frontend/public/favicon.ico` (16/32/48, PNG-in-ICO, write the ICO container by hand), and a contact sheet `docs/design/screenshots/logo-sizes.png` showing the favicon at 16, 32 and 64 px and the maskable icon with a circular mask overlay. You CANNOT run this script (the run rules forbid node scripts): the supervisor runs it after you finish. So write it carefully and keep it simple. Existing `icons/icon-192.png` and `icon-512.png` are referenced by the manifest: keep the same filenames. The manifest needs a maskable entry that points to `icons/icon-maskable-512.png`.
6. `docs/design/LOGO.md`: construction (shapes, grid), colours with hex, clear space (the height of the bolt around the mark), minimum size (mark 16 px, full logo 120 px wide), and the don'ts (no recolouring outside the palette, no stretching, no drop shadows, do not place on busy backgrounds, do not use the mark as the only content of the page heading). The foundation lane writes `docs/design/LAB_THEME.md`; you do not edit it.
