# Lane q1-frontend-lang (frontend language correctness)
Read AGENTS.md first. Never open `.env*`. Do NOT edit `frontend/src/core/` (Kiro), `flow/navigation.ts`, `flow/share.ts`, `components/Share*`, `components/VerifiedBanner.tsx` or `Rate/LanguageSelector.tsx` (lane p3 owns them until merged). Create `docs/reports/agy-q1-frontend-lang-report.md` FIRST (Status IN PROGRESS, DONE at the end, list anything deferred). One BUILD_LOG entry (tool = "agy, reviewed by Claude"). Source: docs/reports/audit-r5-kiro-glue.md (findings with code quotes). Every change needs a meaningful test that drives real code; no always-true assertions.
1. HIGH, frontend/src/flow/ask.ts (~158-163, 279, 383): `caveatForQuestion` ignores the caller's `deps.lang` (for example 'hi-IN') and builds the Spec Ghost caveat in the global UI language, so a Hindi/Gujarati answer gets an English caveat (or the reverse). Make the caveat use the same language as the answer being spoken. Tests: for en, hi, gu the caveat language equals deps.lang even when the global UI language differs.
2. MED, same file (~143-156): the caveat only matches three-letter vertex codes such as "ADC" and misses questions that name a single vertex ("What is the angle at D?"). Match single-letter point ids and P-numbered ids (P1..P999) as well, without matching ordinary capitalised words (I, A as an article, units). Tests with positive and negative cases.
3. HIGH, frontend/src/screens/Explore.tsx (~231, 245, 1277): statusMessage and lastSpokenRef are initialised once from `announced`, so after a mid-session language switch the status text and the "repeat" speech stay in the old language. Make them follow the current language (re-derive the announcement for the current language when the language changes, without re-speaking automatically). Note: statusMessage already re-syncs from the announced prop after the p2 lane; keep that behaviour. Test with a language switch.
Do not change any wording that uses the words verified/correct/checked/approved. New strings (if any) go in en, hi, gu in `frontend/src/i18n/index.ts` in one contiguous block at the END of each language table, plus rows appended to docs/user-test/translation-review.csv and .md.
