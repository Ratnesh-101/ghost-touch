# Audit a3-teach-editor
Read `docs/briefs/audit-common.md` first. Report: `docs/reports/audit-a3-teach-editor.md`.
Focus: functional and accessibility bugs in the teacher editor `#/teach`. Files: `frontend/src/screens/Teach.tsx`, `frontend/src/components/teach/**`, `frontend/src/flow/teach.ts`, `frontend/src/drivers/clipboard.ts`, `frontend/src/styles/teach.css`, the reused `frontend/src/core/correct.ts` (read-only: judge only how the editor USES it), entry points in `frontend/src/App.tsx` and `LabSettings.tsx`.
Hunt for: undo/redo after add/delete/move leaving dangling segments or stale selection; keyboard flows (Tab order, focus trap in the load modal, Escape, arrow nudge step and bounds, Delete on nothing selected); focus lost after actions; screen reader names and live-region announcements for every state change; edits on a function_graph axis fields with invalid/empty/NaN input; add-vertex placement and id collisions; move vertex outside [0,1]; label length caps in the UI vs `LIMITS`; name/note limits enforced in the UI and in encode; "Mark verified" enabled/disabled logic races; stale `verifiedAt` (set when editor opened vs when marked?); editing after generating a link (is the old link/QR still shown as if it matched the new scene?); QR shown for a URL over the cap; loading an existing link into the editor then re-sharing (does it keep or overwrite the old verifier?); layout at 390 px and 1440 px (overflow, touch targets under 48 px, canvas scaling, pointer coordinates when the canvas is letterboxed); memory/URL object leaks; leaving the editor with unsaved edits (data loss without warning); the speech driver cancels the previous utterance on every speak, so find any back-to-back speaks; behaviour when the flag or the Teacher-tools setting is turned off while on the page; i18n keys missing in hi/gu (diff the three tables for `teach.*`, `share.*`).
