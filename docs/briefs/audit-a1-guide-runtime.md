# Audit a1-guide-runtime
Read `docs/briefs/audit-common.md` first. Report: `docs/reports/audit-a1-guide-runtime.md`.
Focus: runtime bugs in Guide my finger on a real phone. Files: `frontend/src/guide/**`, `frontend/src/flow/guide.ts`, guide parts of `frontend/src/screens/Explore.tsx`, `frontend/src/drivers/audio.ts` (guide tone, StereoPanner), `frontend/src/flow/commands.ts` (guide commands), `frontend/src/flow/ask.ts`.
Hunt for: timers or intervals not cleared on unmount, Back or screen change, language switch or scene change while guiding; guide tone left playing after stop/arrive/lift/background tab/visibilitychange; two guides started at once; pulse spam (haptic call every pointermove instead of throttled); stale closures in React effects; pointer events with TalkBack relative cursor (no pointermove, only synthetic events); tick source (what drives timeout when the finger is still?); arrival detection when the target is on a screen edge or when scene is letterboxed (viewport offset/scale errors); speech cancelling itself (the speech driver cancels the previous utterance on every speak: any place where two speaks fire back to back loses the first); hint spam; interaction with the theremin and corner/line haptics (must be suppressed, then restored); audio context suspended before user gesture; Ask answer "Guide me" button when the scene changed between answer and tap; voice commands in hi/gu mis-parsing; `isGuideActive` reading storage on every render.
