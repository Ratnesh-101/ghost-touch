# Audit a6-security-fullstack
Read `docs/briefs/audit-common.md` first (rules and report format; scope there is widened for this lane to the WHOLE app). Report: `docs/reports/audit-a6-security-fullstack.md`.
Backend files: `backend/app/**`, `backend/requirements*.txt`, `backend/requirements.lock`, `render.yaml`, `backend/.env.example` (never open `.env`). Frontend: `frontend/vercel.json`, `frontend/index.html`, `frontend/vite.config.ts`, `frontend/src/api/**`, `frontend/src/drivers/**`. Repo: `.github/workflows/*`, `.gitignore`, `scripts/**`.
Hunt for: missing or weak security headers and CSP (Vercel and FastAPI), CORS misconfiguration (wildcards, credentials, origin reflection, trailing slashes, preview URLs), SSRF or path traversal in any route or in provider calls, upload handling (type sniffing vs extension, decompression bombs in images/PDF, EXIF, huge dimensions, multipart limits, temp files), request-size and rate limits per route and bypasses (X-Forwarded-For spoofing behind Render), error messages leaking internals or keys or file paths, logging of secrets/PII/questions/images, API key handling (keys in URLs, logged exceptions that include headers), timing and DoS paths (regex backtracking, unbounded loops over scene sizes, expensive Canny/contour work on large images, concurrency cap bypass), dependency risk from the lockfile (names and pinned versions only; flag packages with known advisories you are SURE about, never guess), GitHub Actions risks (secrets in logs, `pull_request_target`, unpinned third-party actions, permissions), `service worker` caching of API responses or of authenticated data, localStorage/IndexedDB data that should not persist, clickjacking (frame-ancestors), cookie use (none expected), PWA manifest and scope, open redirects, XSS sinks (`dangerouslySetInnerHTML`, `innerHTML`, `eval`, `new Function`, `document.write`, `href` built from data), prototype pollution in JSON handling, and anything an anonymous visitor could do to run up the owner's paid LLM bill.
